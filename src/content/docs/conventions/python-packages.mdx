`ups-sdk` is the model for the rest.

## Names

| Repository | Distribution | Import |
|---|---|---|
| `ups-sdk` | `tailstory-ups` | `ups_sdk` |
| `usps-sdk` | `tailstory-usps` | `usps_sdk` |
| `fedex-sdk` | `tailstory-fedex` | `fedex_sdk` |
| `hermes` | `tailstory-hermes` | `hermes` |

- **An import name never carries the organization's name.** A distribution may; `module-name` under `[tool.uv.build-backend]` sets the import name when the two differ.

## Layout

```
.github/workflows/   ci.yaml, docs.yaml, python-publish-pypi.yaml, actions.lock
docs/                conf.py, index.rst, changelog.rst
src/<import name>/
tests/
.gitattributes       * text=auto eol=lf
.pre-commit-config.yaml
noxfile.py
pyproject.toml
uv.lock
wrangler.jsonc
```

- **Sphinx sources sit directly in `docs/`.** No `docs/source`.
- **Built docs go to `site/` at the repository root.** Git ignores it.
- **Every tool's cache is under `.cache/`.**

## pyproject.toml

- **The build backend is `uv_build`.**
- **`requires-python` is `>=3.14`.**
- **HTTP goes through `niquests`.**
- **Dependency groups are `dev`, `docs` and `tests`.**
- **Ruff selects `ALL`.** Each ignore carries its reason in a comment.
- **`documentation` is `https://docs.tailstory.dev/<repository>/`.**

## Checks

`ci.yaml` has two jobs, and `nox` runs the same commands locally.

| Job | Commands |
|---|---|
| `lint` | `prek run --all-files`, `ruff format --check .`, `ruff check .`, `mypy --strict src/ tests/`, `ty check .` |
| `test` | `python -m coverage run -m pytest -v`, then `coverage xml` |

- **The same code passes mypy and ty.** A failure is fixed in the code, not with an ignore for one checker.
- **A failed coverage upload does not fail the job.**

## Docs

- **The build is `sphinx-build --builder dirhtml --nitpicky docs site`.**
- **`autoapi_dirs` is `["../src"]`.**
- **`docs.yaml` builds the docs on every pull request and deploys nothing.** [The package's Worker](/conventions/sites/#a-librarys-docs) serves them.

## Releases

- **Publishing a GitHub release publishes to PyPI.** `python-publish-pypi.yaml` builds on every push and pull request, and its `publish` job runs only on a published release.
- **PyPI trusts the workflow.** No token is stored.
