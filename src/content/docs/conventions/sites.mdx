- **A site is a Cloudflare Worker that serves static assets and runs no script.**
- **Workers Builds deploys a site when its pull request merges.** No workflow deploys one.
- **A Worker's custom domain makes its own DNS record.** `infrastructure` neither creates nor deletes it.

| Address | Repository | Holds |
|---|---|---|
| `tailstory.dev` | `tailstory-dev` | The company site. |
| `docs.tailstory.dev` | `docs` | Tailstory's own docs: everything that is not a library. |
| `docs.tailstory.dev/<repository>/` | The library's own | That library's docs. |
| `wiki.tailstory.dev` | `wiki` | Notes on other vendors' products, at `/<vendor>/<product>/`. |

## A library's docs

A `wrangler.jsonc` at the root of the library's repository:

```jsonc
{
  "name": "<repository>-docs",
  "compatibility_date": "<today>",
  "build": {
    "command": "uv run --locked --group docs sphinx-build --builder dirhtml --nitpicky docs site"
  },
  "assets": {
    "directory": "./site",
    "base_path": "/<repository>"
  },
  "routes": [
    { "pattern": "docs.tailstory.dev/<repository>", "zone_name": "tailstory.dev" },
    { "pattern": "docs.tailstory.dev/<repository>/*", "zone_name": "tailstory.dev" }
  ],
  "workers_dev": false,
  "previews": {}
}
```

- **`base_path` puts the docs under the route without a subfolder in `site/`.** It needs Wrangler 4.148 or newer.
- **A route wins over the custom domain on the same hostname.** `docs` answers every path no library claims.
